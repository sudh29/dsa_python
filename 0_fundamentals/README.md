# 🧩 0. Fundamentals

A curated collection of introductory algorithmic building blocks and classic interview warm-up problems in Python 3.12.

---

## 📌 Problem Index

| Problem | File | Pattern | Time Complexity | Space Complexity |
| :--- | :--- | :--- | :---: | :---: |
| **Prime Check** | [`prime_check.py`](prime_check.py) | Trial Division up to $\sqrt{N}$ | $O(\sqrt{N})$ | $O(1)$ |
| **Anagram Check** | [`anagram_check.py`](anagram_check.py) | Frequency Counting / Hash Map | $O(N)$ | $O(1)$ |
| **Swap Numbers** | [`swap_numbers.py`](swap_numbers.py) | XOR In-Place Swap & Tuple Packing | $O(1)$ | $O(1)$ |
| **Count Set Bits** | [`count_set_bits.py`](count_set_bits.py) | Brian Kernighan's Bit Manipulation | $O(K)$ | $O(1)$ |
| **Unique Paths in Grid** | [`unique_paths_grid.py`](unique_paths_grid.py) | Dynamic Programming / Combinatorics | $O(M \times N)$ | $O(N)$ |

---

## 🚀 Running Demonstrations

All solutions are self-contained and non-blocking:

```bash
python3 0_fundamentals/prime_check.py
python3 0_fundamentals/anagram_check.py
python3 0_fundamentals/swap_numbers.py
python3 0_fundamentals/count_set_bits.py
python3 0_fundamentals/unique_paths_grid.py
```
